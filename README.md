# 你老师最像谁？

[English](./README.en.md)

一个纯娱乐的老师类型测试站。输入一个老师代号或外号，回答 24 道单选题，就能得到一张角色结算卡。项目是纯静态前端应用，适合直接部署到 GitHub Pages。

> 本测试只用于娱乐，不构成对任何现实人物的评价。请不要输入真实姓名、照片或个人隐私信息。

## 在线访问

GitHub Pages:

https://nightt5879.github.io/who_is_your_teacher/

## 功能

- 中文 / English 双语界面、题目和结果页文案。
- 24 道单选题，浏览器本地完成答题和匹配计算。
- 17+n 个结果，其中部分隐藏结果需要满足特殊条件才会出现。
- 首页显示全站累计参与人数。页面访问会调用公开计数接口累加；如果接口不可用，会回退到本地显示，不影响答题。
- 结果页包含角色大图、8 维雷达、评分、短评、名言、生存攻略和隐藏款标识。
- 支持保存 1080x1920 竖版结果图；失败时可复制结果文案。
- 结果页提供 GitHub 仓库入口，欢迎反馈、讨论和二次创作。

## 计算方式

测试内部使用 8 个维度描述老师画像：

- 作业轰炸
- 控制纪律
- 考试突袭
- 混沌整活
- 谜语玄学
- 摆烂失联
- 人性关怀
- 压迫威慑

每个选项会给部分维度增加分数，也可能给某些结果增加少量倾向加成。完整流程如下：

1. 累加 24 个答案的维度分数和结果倾向加成。
2. 根据题库自动计算每个维度的最大可能分，并把用户画像归一化到 0-100。
3. 使用加权曼哈顿距离，把用户画像和结果原型向量进行匹配。
4. 加入选项倾向加成和极小的确定性混沌因子，用于打破接近结果。
5. 先计算常规结果，再判断隐藏结果触发条件；隐藏结果只有在条件满足且分数足够接近时才会覆盖常规结果。

前端只展示最终结果和 8 维画像，不展示内部 boost、距离分或排序细节。

## 隐私

- 不需要登录。
- 不上传老师姓名、答题内容或结果。
- 参与人数计数只调用公开计数接口做一次访问累加，不携带用户输入内容。
- 结果图在浏览器本地生成。

## 本地开发

```bash
npm install
npm run dev
npm test
npm run build
```

默认 Vite base 是 `/who_is_your_teacher/`，对应当前 GitHub Pages 仓库路径。

## 部署

仓库内包含 GitHub Actions workflow。推送到 `main` 后会自动：

1. 安装依赖
2. 运行测试
3. 构建 Vite 静态产物
4. 上传并部署到 GitHub Pages

GitHub 仓库 Settings 里需要启用 Pages，并选择 GitHub Actions 作为发布源。
